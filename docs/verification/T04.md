## 実装中に起きたこと

- 最初のビルドで、デスクトップ版の `build/relwithdebinfo` と `build/release` が Debug で設定されていた。T03 の確認のときに `build/` が作り直され、デスクトップ版のディレクトリがなくなっていたところを、AI が構成を指定せずに設定したため（CMakeLists.txt は、指定がないと Debug にする）。構成を明示して設定し直し、上の結果はすべて設定し直したあとのもの。CMakeLists.txt が、指定した構成を書き換えないことも確かめた
- ImGui の関数（`GetIO`、`IniFilename`、`SetNextWindowPos`、`Begin`、`Text`、`End`、`ImGuiCond_FirstUseEver`、`ImGuiWindowFlags_AlwaysAutoResize`）は、取得した `imgui.h` で宣言と引数を確かめてから使った。rlImGui の関数は `rlImGui.h` で、`GetFPS` と `GetFrameTime` は `raylib.h` で確かめた
- rlImGui の `premake5.lua` が想定する ImGui は 1.92.7 だが、ADR 0001 の `v1.92.9b` でビルドが通った
