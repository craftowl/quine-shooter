## 確かめられなかったこと

- Windows でのシンボリックリンクとコピーの切り替え、Visual Studio のジェネレータでのリンクの経路（T12 の決定どおり、確かめない。Windows の CI は Release だけで、Release はいつもコピー）
- Windows で、`cmake -E rm -rf` がディレクトリへのシンボリックリンクを消せるか（同じ理由で、Windows の Debug のビルドを2回続けたときの動きは確かめていない）

## わかったこと

- T07 のエラー画面は長い行を折り返さなかったので、理由が画面の右端で切れた。T12b の作業として、理由の行を空白の位置で折り返すように直した（人が決めた）。毎フレーム描くので、確保をしない書き方にした
- 開始位置が自機の動ける範囲の外のとき、最初の `update()` まで範囲の外に描かれることがあった。`Game::start` で範囲に収めるように直した（レビューの気づきを受けて、人が決めた）
- 読み直しに失敗したとき、ログが2行出る（`parse_params` の理由と、ホットリロードの「Reload failed」）。ADR 0006 の「失敗した場所で TraceLog に出す」と、ホットリロードの状態のログの両方による
- 確認の途中で、作業用のビルドディレクトリ2つに同じ依存の置き場所を使わせたため、Debug の依存のビルドの設定が壊れた（コードの問題ではない）。Debug のビルドディレクトリを作り直した。依存の置き場所は、ビルドディレクトリごとに分ける
