## 実装中に起きたこと

- raylib の関数（`SetConfigFlags`、`FLAG_WINDOW_HIDDEN`、`GetCurrentMonitor`、`GetMonitorWidth`、`GetMonitorHeight`、`GetMonitorPosition`、`SetWindowSize`、`SetWindowPosition`、`ClearWindowState`、`LoadFontEx`、`IsFontValid`、`UnloadFont`、`SetTextureFilter`、`TEXTURE_FILTER_POINT`、`Camera2D`、`BeginMode2D`、`EndMode2D`、`DrawTextEx`、`MeasureTextEx`、`TextFormat`、`GetApplicationDirectory`、`TraceLog`）は、取得した `raylib.h` で宣言と引数を確かめてから使った。`emscripten_run_script_int` は emsdk の `emscripten.h` で確かめた
- raylib のソースで確かめたこと
  - `GetApplicationDirectory()` は、macOS では実行ファイルのディレクトリを末尾の `/` 付きで、wasm では `"/"` を返す
  - `GetMonitorWidth()` と `GetMonitorHeight()` はモニターの表示モードの大きさを返す。macOS では GLFW が `CGDisplayModeGetWidth` を使うので、ピクセルではなくポイントで返る。ウィンドウの大きさもポイントなので、そのまま比べられる
  - `LoadFontEx` は、ファイルが読めないと中身が空のフォントを返す（組み込みのフォントではない）。`IsFontValid` で見分けられる
  - テクスチャの既定のフィルタは `GL_NEAREST`。明示するため、フォントのテクスチャに `TEXTURE_FILTER_POINT` を設定した
