## わかっている問題

`/code-review medium` の指摘（低。実装のあとのレビューで低だけなので、直さずにここに書いた）：

- `quines/` の `boss_` で始まらない `.cpp` に出すメッセージが、tasks.md の「仕組みの取り違え」の文言（「雑魚は Quine のファイルを使わない」）と違う。実装は「Quine のファイルを使えるのはボス（boss_ で始まる ID の敵）だけ（雑魚は QUINE 範囲を使う。ADR 0009）」を出す。違反として止まる動きは同じ
- 2回目の `/code-review medium` の指摘（低）：生成物はボスの Quine をふつうの文字列リテラルにして埋め込み、`\` と `"` だけをエスケープする。`#` のマスには `?` を置けるので、Quine の行に三文字表記（`??=`、`??/` など）があると、生成した `enemy_text_data.cpp` で clang が `-Wtrigraphs` を出し、`-Werror` でゲームのビルドが止まる（quine_pack の違反としては出ない）。Quine の中では生文字列の中にあるので、Quine 自体は通る。今のリポジトリにボスはいないので、起きるのは T15c2 の生成ツールが `??` を出したとき。直し方の案は、生成物で `?` を `\?` にするか、quine_pack で三文字表記を違反にするか
